## 📘 Description
**MyMarvin** est un projet d'infrastructure DevOps visant à automatiser l'installation, la configuration et le déploiement d'un serveur d'intégration continue **Jenkins** à l'aide de scripts **Job DSL (Groovy)** et de conteneurs Docker.

## ⚙️ Fonctionnalités
- Déploiement automatisé de l'instance Jenkins via Docker Compose.
- Déclaration des tâches de build, de test et de packaging sous forme de code (`job_dsl.groovy`).
- Déclencheurs de build automatiques sur commits GitHub.
